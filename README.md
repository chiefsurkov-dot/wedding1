# Свадебное приглашение — Алексей & Дарья

Статичный одностраничный сайт: `index.html`, `styles.css`, `script.js`.
Все тексты, даты, адрес, программа, палитра дресс-кода и контакты находятся в `config.js`.

Ответы гостей: укажите `rsvp.endpoint` (например, Formspree) — иначе форма откроет письмо на `rsvp.email`.

Публикация: GitHub Pages (Settings → Pages → ветка, корень) или любой статический хостинг.
